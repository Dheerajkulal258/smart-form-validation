# 🚀 Smart Form Validation System

A full-stack web application that performs **real-time form validation**, displays **password strength**, and stores user data in **MongoDB** with dynamic UI updates.

---

## 📌 Features

- ✅ Real-time input validation (Name, Email, Password)
- 🔐 Strong password rules (uppercase + number required)
- 📊 Password strength indicator (Weak / Medium / Strong)
- ⚡ Dynamic DOM updates (no page reload)
- 🚫 Prevents submission if invalid
- 💾 Stores user data in MongoDB
- ❌ Proper error handling (frontend + backend)

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Templating Engine:** EJS

## ⚙️ Installation & Setup

### 1. Clone repository
```

git clone [https://github.com/your-username/smart-form-validation.git](https://github.com/your-username/smart-form-validation.git)

```

### 2. Navigate to project
```

cd smart-form-validation

```

### 3. Install dependencies
```

npm install

```

### 4. Start MongoDB
Make sure MongoDB is running locally:
```

mongod

```

### 5. Run the server
```

node server.js

```

### 6. Open in browser
```

[http://localhost:3000](http://localhost:3000)

```

## 🧪 How It Works

1. User enters data in form  
2. Frontend validates input in real-time  
3. Data is sent to backend using `fetch()`  
4. Backend saves data to MongoDB  
5. UI updates dynamically without page reload
